## Run locally

Open the folder in a browser or serve it locally using a static server.

For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

### Recommended repository naming

If your GitHub username is something like:

```text
yourusername
```

Then create a repository named:

```text
yourusername.github.io
```

This gives you a public profile site such as:

```text
https://yourusername.github.io/
```

If you prefer a project portfolio site instead, use a repo name like:

```text
naveed-aftab-usmani-portfolio
```

Then the URL becomes:

```text
https://yourusername.github.io/naveed-aftab-usmani-portfolio/
```

### Deployment steps

1. Create a new GitHub repository.
2. Upload this folder or push it with Git.
3. In the repository settings, open Pages.
4. Select the main branch and root folder.
5. Save and wait for GitHub Pages to publish.
